## 概述：4种包装形态定义

| 形态 | 英文 | 定义 | BUpack 对应产品 |
|------|------|------|----------------|
| **电商快递外包** | E-commerce Shipping / Mailer Box | 产品发货时的最外层瓦楞纸箱，需要保护产品+品牌展示 | Mailer Box |
| **礼品套装包装** | Gift Set Box | 多件产品组合出售时的精美礼盒，通常是硬盒+内托 | Gift Box / Rigid Box |
| **订阅盒** | Subscription Box | 月度/季度配送的标准化纸盒，每期换主题设计 | Subscription Box |
| **产品简包/第一包装** | Primary Product Packaging | 产品本身的纸盒包装，消费者最先接触的品牌载体 | Folding Carton / Sleeve |

## 🕯️ 行业1：香薰蜡烛 & 家居香氛

### 1. 电商快递外包（Mailer Box）
- **参考链接**：https://dcustomboxes.com/product/candle-mailer-boxes/
- **设计要点**：
  - 使用E型瓦楞（轻量）+ 模切内托固定蜡烛玻璃罐
  - 单面/双面全彩印刷，突出品牌Logo
  - 常见尺寸根据蜡烛罐直径+1英寸缓冲空间设计
  - 可加烫金/烫银、击凸工艺提升质感
- **参考图片**：
  - https://dcustomboxes.com/wp-content/uploads/2026/03/2-77.png
  - https://dcustomboxes.com/wp-content/uploads/2026/03/3-78.png
  - https://dcustomboxes.com/wp-content/uploads/2026/03/1-49.png

### 2. 礼品套装包装（Gift Set Box）
- **参考链接**：https://packsar.com/candle-packaging/
- **设计要点**：
  - 硬质翻盖盒/磁吸盒，内部多层分隔
  - 三件套蜡烛礼盒：3个独立槽位+品牌丝带
  - 节日限定版印刷（圣诞、情人节主题）
  - 内盒可印刷品牌故事或香味说明
- **代表品牌**：Otherland（艺术火柴盒式）、Boy Smells（大胆配色）、Voluspa（浮雕纸盒）

### 3. 订阅盒（Subscription Box）
- **参考链接**：https://packlane.com/products/mailer-box
- **设计要点**：
  - 标准化尺寸，每月更换外盒印刷主题
  - 内置分层隔板，可容纳蜡烛+火柴+品牌卡
  - 内部印刷惊喜信息，鼓励社交分享
  - 可重复密封设计（磁吸翻盖）
- **代表品牌**：Homesick（城市主题每月更换）

### 4. 产品简包/第一包装（Primary Packaging）
- **参考链接**：https://www.dreamcustomboxes.com/candle-boxes/
- **设计要点**：
  - 卡纸翻盖盒，直接包裹蜡烛罐
  - 可开窗设计展示蜡烛颜色
  - 哑膜/光膜可选，提升触感
  - 印有香型名称、燃烧时间、成分信息

## 💍 行业2：珠宝 & 轻奢配饰

### 1. 电商快递外包（Mailer Box）
- **参考链接**：https://packfancy.com/pages/custom-jewelry-packaging
- **设计要点**：
  - 小型瓦楞邮寄盒（常见6x4x2英寸）
  - 内部填充缓冲材料保护珠宝盒
  - 外盒印刷品牌Logo，简约高端
  - 防篡改密封设计
- **参考产品**：PackFancy Custom Mailer Boxes

### 2. 礼品套装包装（Gift Set Box）
- **参考链接**：https://luxopack.com/
- **设计要点**：
  - 硬质翻盖盒/抽屉盒，内衬绒布/丝绸
  - 项链+耳环+手链套装分层展示
  - 磁吸闭合，烫金Logo
  - 附赠品牌擦银布和保养卡
- **代表品牌**：Mejuri（灰白硬盒+绒布内托）、Gorjana（磁吸翻盖盒）

### 3. 订阅盒（Subscription Box）
- **设计要点**：
  - 月度珠宝订阅：标准化外盒+每月换内卡设计
  - 内含品牌故事卡、搭配建议卡
  - 盒型偏小巧精致，符合珠宝客单价
- **代表品牌**：Ana Luisa（碳中和珠宝订阅）

### 4. 产品简包/第一包装（Primary Packaging）
- **参考链接**：https://packfancy.com/products/magnetic-jewelry-box
- **设计要点**：
  - 戒指盒：2x2英寸硬盒+海绵内托
  - 项链盒：细长翻盖盒+挂钩固定
  - 耳环盒：对开式+镜子内衬
  - 材质：硬纸板+绒布/丝绸内衬
  - 工艺：烫金Logo、磁吸闭合

## 🍫 行业3：巧克力 & 高端糖果

### 1. 电商快递外包（Mailer Box）
- **参考链接**：https://epackcn.com/step-by-step-guide-to-creating-custom-printed-mailer-boxes-for-dtc-and-subscription-brands/
- **设计要点**：
  - 保温内衬（夏季配送需加隔热层）
  - 瓦楞邮寄盒+内部固定巧克力盒
  - 外盒标注"易碎/保温"标识
  - 双面印刷：外盒品牌展示，内盒感谢语

### 2. 礼品套装包装（Gift Set Box）
- **设计要点**：
  - 硬质翻盖盒+定制内托（每个巧克力独立槽位）
  - 视窗设计展示巧克力造型
  - 缎带+磁吸闭合
  - 节日限定印刷（情人节、圣诞、母亲节）
- **代表品牌**：Compartés（艺术插画纸盒）、Sugarfina（透明视窗立方体盒）

### 3. 订阅盒（Subscription Box）
- **设计要点**：
  - 月度巧克力品鉴盒：标准化尺寸+每月换主题
  - 内含品鉴卡、产地故事、搭配建议
  - 分区隔板，不同口味分开放置
- **代表品牌**：Vosges Haut-Chocolat（紫色调硬盒）

### 4. 产品简包/第一包装（Primary Packaging）
- **设计要点**：
  - 巧克力排块：卡纸折叠套盒
  - 松露巧克力：独立小纸盒+透明窗
  - 礼盒装巧克力：抽屉式纸盒
  - 印有可可含量、产地、品鉴笔记
- **代表品牌**：Tony's Chocolonely（彩色纸盒+反奴隶制信息）

## ✒️ 行业4：高端文具 & 生活方式礼品

### 1. 电商快递外包（Mailer Box）
- **设计要点**：
  - 扁平瓦楞邮寄盒（适配笔记本/贺卡尺寸）
  - 内部加固防折角
  - 简约品牌印刷
  - 适合书本/笔记本/日历等扁平产品

### 2. 礼品套装包装（Gift Set Box）
- **参考链接**：https://riflepaperco.com/
- **设计要点**：
  - 硬质翻盖礼盒，内含笔记本+笔+贺卡+贴纸
  - 花卉/几何图案印刷，品牌辨识度极高
  - 缎带或磁吸闭合
  - 内衬分隔设计
- **代表品牌**：Rifle Paper Co.（花卉图案纸盒）、Papier（定制化日记本礼盒）

### 3. 订阅盒（Subscription Box）
- **设计要点**：
  - 月度文具盒：标准化尺寸+每月主题设计
  - 内含笔记本、贴纸、笔、便签等
  - 内盒印刷创意提示或手写字体
- **代表品牌**：Papier Tigre（几何图案硬盒）

### 4. 产品简包/第一包装（Primary Packaging）
- **设计要点**：
  - 笔记本：腰封/书套式卡纸包装
  - 贺卡套装：抽屉式纸盒
  - 钢笔：细长翻盖盒+内衬
  - 印有品牌故事、纸张规格

## 🍵 行业5：茶叶 & 特色饮品

### 1. 电商快递外包（Mailer Box）
- **设计要点**：
  - 中型瓦楞邮寄盒，内置分隔板
  - 外盒印刷品牌和茶叶品类
  - 适合多罐/多盒茶叶组合发货

### 2. 礼品套装包装（Gift Set Box）
- **参考链接**：https://www.gvpak.com/blogs/best-tea-packaging-2025-top-10-creative-tea-packaging-design-ideas
- **设计要点**：
  - 硬质翻盖/抽屉式礼盒，内部多格分区
  - 4-6种茶叶独立小罐+品鉴卡
  - 中式/日式/英式风格印刷
  - 磁吸闭合+丝带
- **参考案例**：
  - T2 迷你水果茶盒（水果造型仿生设计）
  - Teastar 星形茶叶盒（创意造型+鲜艳色彩）
  - DAVIDsTEA 抽屉式茶盒（清新绿色调）
- **参考图片**：
  - https://www.gvpak.com/wp-content/uploads/2025/06/Best-Tea-Packaging-2025-2.-T2-Big-Creativity-in-Mini-Fruit-Tea-Packaging.png
  - https://www.gvpak.com/wp-content/uploads/2025/06/Best-Tea-Packaging-2025-10.-Teastar-Star-Shaped-Tea-Packaging.png

### 3. 订阅盒（Subscription Box）
- **设计要点**：
  - 月度茶品鉴盒：标准化尺寸+每月4款新茶
  - 内含品鉴卡、冲泡指南、产地故事
  - 独立小袋/小罐分装
  - 盒内印刷茶文化知识
- **代表品牌**：Sips by（月度茶订阅）、DAVIDsTEA（季节限定盒）

### 4. 产品简包/第一包装（Primary Packaging）
- **参考链接**：https://99designs.com/inspiration/packaging/tea
- **设计要点**：
  - 茶袋：独立小纸袋/纸盒
  - 散装茶：卡纸罐/圆筒盒
  - 茶包礼盒：抽屉式小盒（10-20包）
  - 印有茶种、产地、冲泡方法
- **参考案例**：
  - Tea Forté 金字塔茶袋+礼盒
  - Chatu 模塑纸浆茶盒（中国茶园地形灵感）

## 🐾 行业6：宠物零食 & 宠物订阅盒

### 1. 电商快递外包（Mailer Box）
- **设计要点**：
  - 中型瓦楞邮寄盒，坚固耐压
  - 外盒印刷品牌+宠物主题插画
  - 适合狗零食、猫玩具等多品类混装

### 2. 礼品套装包装（Gift Set Box）
- **设计要点**：
  - 硬质翻盖礼盒，内含零食+玩具+配件
  - 宠物生日/节日主题印刷
  - 分区隔板，不同品类分类放置
- **代表品牌**：Jinx（黑色纸盒+亮色Logo）

### 3. 订阅盒（Subscription Box）
- **参考链接**：https://www.lauramechling.com/work/barkbox
- **设计要点**：
  - **BarkBox 模式**：月度主题盒，标准化尺寸
  - 每月更换主题设计（如"ThrowBark Thursday"复古拼贴、"Paradise Unleashed"热带度假）
  - 内部结构：三折式（trifold）或风琴式插页（accordion insert）
  - 附赠贴纸页、主题内衬
  - 核心设计理念：盒子本身就是体验，鼓励用户拍照分享
- **代表品牌**：BarkBox（月度主题变换）、KitNipBox（猫玩具订阅）

### 4. 产品简包/第一包装（Primary Packaging）
- **参考链接**：https://fursnpaws.com/dog-treat-packaging-ideas
- **设计要点**：
  - 狗零食：自立袋+外卡纸套盒
  - 宠物补充剂：小纸盒+说明书
  - 宠物玩具：开窗纸盒展示玩具造型
  - 印有成分表、喂食指南、品牌故事
