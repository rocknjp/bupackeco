> 整理时间：2026-06-09

## 核心流程（4步法）

### Step 1：关键词挖掘与去重
1. 用 **Semrush** 搜索行业关键词
2. 筛选：语言选英文，匹配类型选「相关性」
3. 导出到本地 Excel
4. **去重技巧**：在关键词右侧新增一列「中文翻译」，然后用 Excel「删除重复项」功能，基于中文列去重（消除搜索意图完全重复的词）
5. 效果：从 8300 个词 → 去重后约 876 个有效关键词

### Step 2：关键词聚合分组
1. 将去重后的关键词放入**关键词聚合工具**
2. 工具按「关键词相似度 + 搜索意图」自动合并划分
3. 处理完成后导出表格，每个组别包含：
   - 一组搜索意图一致的关键词
   - **内容类型标注**（博客文章 or 产品页）—— 这是关键！

> ⚠️ 注意：基于搜索意图的聚合可能需要 10-15 分钟（800+ 词约 13 分钟）

### Step 3：AI 生成网站架构
1. 将关键词表格 + **品牌信息** + **受众群体信息** 发给 **Gemini**
2. 让 Gemini 分析并生成网站架构
3. **优势**：基于真实有搜索量的关键词布局，不会让 AI「创造」虚假关键词

### Step 4：自动化内容创作与发布
1. 将网站架构信息粘贴到「SEO 网站架构生成器」
2. 自动生成完整网站架构
3. 网站上线后，用自动化工作流实现：
   - 自动处理表格中的关键词数据
   - 根据标注的内容类型创作内容
   - 自动发布到对应内容模块
4. 人工只需：审核 → 修改问题 → 确认发布
